# Profile Card UI

A simple and clean **Profile Card** built using **HTML** and **CSS**.
This project is beginner-friendly and helps understand concepts like:

* Box Model
* Border Radius
* Background Image
* Text Alignment
* Buttons
* Basic Card Design

---

## 🚀 Features

* Circular profile image
* Simple card layout
* Responsive styling basics
* Clean UI design
* Beginner-friendly code structure

---

## 🛠️ Technologies Used

* HTML5
* CSS3
